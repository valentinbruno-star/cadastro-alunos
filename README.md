# Sistema de Cadastro de Alunos

Projeto desenvolvido em Python utilizando Programação Orientada a Objetos (POO).

## Funcionalidades
- Cadastro de alunos com duas notas.
- Cálculo da média.
- Validação de notas entre 0 e 10.
- Situação do aluno (Aprovado ou Recuperação).
- Listagem de alunos.
- Busca pelo nome.
- Salvamento dos dados em arquivo TXT.

## Como executar
É necessário ter o Python 3 instalado.

No terminal, execute:

```bash
python cadastro.py
```
